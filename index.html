Introdução: HTML

O HTML (HyperText Markup Language, ou em português Linguagem de Marcação de Hipertexto é a linguagem de marcação padrão usada para criar e estruturar páginas da web.

Ele define o esqueleto e a organização de elementos visuais — como textos, imagens, tabelas e links — que os navegadores leem e exibem aos utilizadores.

Conceitos Básicos

Tags principais

  1. <!DOCTYPE html> :Deve ser sempre a primeira linha de código nos teus arquivos HTML. Isso informa ao navegador qual versão de HTML ele deve esperar.
  2. <html> :Vai conter todo o seu código HTML.
  3. <head> :Vai conter as informações sobre a página da web, como o título
  4. <body> :Vai conter tudo o q os leitores conseguem ver.

Tags secundárias

  1. <title> :Adiciona um título o tua página da web (usa-se dentro da tag < head >
  2. <div> :Funciona como uma caixa invisível para juntar vários elementos e organizá-los.
  3. <p> :Serve para criar um parágrafo
  4. <ol> :Serve para criar uma lista ordenada
  5. <ul> :Serve para criar um lista sem ordem
  6. <li> :Serve para criar um item de uma lista
  7. <a href="inserir ligação escolhida"> :As "Anchor tags" são usadas para criar links para páginas internas, páginas externas ou conteúdos na mesma página.
  8. <img src="inserir ligação escolhida"> :Serve para inserir uma imagem na página
  9. <video src="inserir ligação escolhida"> :Serve para inserir um vídeo na página
  10. <table> :Serve para criar uma tabela
  11. <!-- comment -- > :Serve para adicionar um comentário que apenas aparecerá no sódigo (não será visível para os leitores)

Nota: Todas as tags tem a sua forma aberta como a forma fechada:

< > (Abrir): É a tag de abertura. Indica ao navegador onde o elemento e a sua formatação começam.

< /> (Fechar): É a tag de fecho. Tem sempre uma barra de fração (/) antes do nome e indica ao navegador onde o elemento termina.
